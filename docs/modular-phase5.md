# 공룡3 5차: 손보기 창 버튼과 화면 맞춤

기준은 `modular@8021a10`, 운영 `c3757a1f-1b5a-4abc-8a81-941442460f58`이다. 배포 전 태그 `2026-11-10-4차운영`은 기준 커밋을 가리킨다. 운영 결과와 캡처는 작업 루트 `85_공룡3_모듈화/5차결과.md`, `5차캡처/`에 기록한다.

- AI 창의 아래 버튼은 종류별 `다른 … 고르기`, `다시 그려줘`, 기존 확인 버튼 순서다. 직접 그리기는 종류별 `다른 … 고르기`와 기존 확인 버튼만 둔다.
- 우상단 닫기 버튼을 없애고 기존 취소 콜백을 아래 흰 버튼에 연결했다. Esc와 확인 전 게임 보존, 재생성·확인 동작은 유지한다.
- 실제 제목·안내·버튼 높이를 측정해 그림판 표시 크기를 조절한다. 그림 데이터와 종횡비는 유지한다. 낮은 화면에서만 여백을 줄이고 팔레트 높이는 필요한 만큼만 축소한다.
- 앱 변경은 `assets/practice/grade1-pixel.js`, `grade1-pixel.css` 두 파일이다. 서버·게임 규칙·수업 데이터·운영 Wrangler 설정은 변경하지 않는다.

검사는 `MODULAR_CAPTURE_DIR`를 `5차캡처` 절대 경로로 지정하고 [4차 문서](modular-phase4.md)의 기존 9개 자동 검사와 다음을 실행한다.

```powershell
node scripts/modular-phase5-test.cjs
```

새 검사는 실제 수업 iframe 구조에서 1280×720, 1366×768, 1920×1080, 1024×768, 768×1024의 AI 3종·직접 그리기·최대 21색을 확인한다. 종류별 새 버튼·이전 게임 보존·같은 단계 재선택·Esc·재생성·확인을 검증한다. 가상 로컬 수업과 AI 응답만 사용하며 실제 수업·AI·DB에는 접근하지 않는다. 화면·터치는 Chromium 재현이며 실제 태블릿 검증은 아니다.

배포는 사용자 지정 명령 `npx --no-install wrangler deploy --config wrangler.json --keep-vars`를 dino3에서 실행한다. `modular-phase5-deploy-verify.cjs --before`는 기준 운영을 확인하고, 배포 후 같은 스크립트에 새 버전 ID를 전달하면 적용률 100%, 변경 정적 파일·Worker 소스 SHA-256, `/api/health`·`/lesson` 200, 설정·보호 브랜치 유지를 확인한다. 이 검증도 읽기 전용이며 수업·게시판·DB API는 호출하지 않는다.
