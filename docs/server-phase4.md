# 4차 코드 밑그림 서버

`modules/entry.js`의 AI 게이트웨이 구간만 직접 편집했다. 원본 빌드·소스맵 복원 없이 수정하는 이유는 [2차 서버 문서](server-phase2.md)와 같다. 교실·게시판·DB 코드, 운영 Wrangler 설정은 수정하지 않았다.

## 코드 생성

캐릭터·장애물·선물은 다시 `mode:'slot'`의 함수 코드 응답을 쓴다. 함수 이름·인자, 허용 Canvas API, 최대 6,000자와 숫자 리터럴 상한 200 이하 반복 등 2차 안전 계약을 유지한다. 클라이언트에서 AST·Worker 검사를 한 뒤 코드를 비트맵으로 렌더한다. 서버는 생성 코드를 실행하지 않는다.

- 1학년용 귀여운 픽셀 아트, 작은 네모 여러 개, 진한 외곽선, 70% 이상 채우는 목표를 프롬프트에 추가했다. 캐릭터는 오른쪽 옆모습과 연결된 머리·몸통·다리, 장애물은 바닥에 붙은 덩어리, 선물은 대상의 주된 형태·색을 요구한다.
- 캐릭터 stand는 44×47, 장애물 밑그림은 44×47, 선물 밑그림은 24×24다. 선물 함수는 `v.w`·`v.h`에 대한 비율을 써 게임의 16×16과 편집기의 24×24에 모두 대응한다. hero의 duck 59×25 등 기존 자세 계약도 유지한다.
- `current`는 이전 칸 소스 문자열만 받는다. 새 캐릭터 선택은 클라이언트가 이 문자열을 보내지 않거나 빈 문자열로 보낸다. 프롬프트도 빈 `current`에서 이전 캐릭터를 이어받지 않도록 지시한다.
- `redraw`·`retry` 선택 필드는 boolean만 받는다. 서버가 고정 지시를 별도로 추가하므로 2,000자 사용자 요청의 재생성·재시도에도 요청문 길이가 늘지 않는다.
- 불투명 칸 기준(캐릭터·장애물 25%, 선물 20%)과 작은 조각 제거 후 최대 연결 덩어리 80% 기준을 프롬프트에도 명시했다. 실제 통과 여부는 클라이언트 렌더 검사가 판단한다.

```json
{"mode":"slot","slot":"hero","request":"판다를 그려 줘.","current":"","redraw":false,"retry":false}
```

## 9단계 코드 수정 분류

```json
{"mode":"route","artMode":"code","request":"캐릭터 색 파랗게","current":{"hero":"function drawHero(ctx,v){...}"},"config":{"speedMultiplier":1,"initialLives":1,"soundPreset":"default"}}
```

`artMode:'code'` 라우터를 추가했다. 캐릭터·장애물·선물은 `{"slot":"hero|obstacle|item","request":"수정 요청"}`으로 대상을 고른다. 클라이언트가 해당 칸 코드가 있을 때만 `slot` 요청의 `current`로 보내 수정한다. 코드가 없으면 클라이언트가 직접 그린 그림 안내와 손보기 창을 연다. 라우터가 현재 코드 없는 칸을 새 코드로 대체하지 않는다.

배경은 기존 `{"slot":"background","code":"..."}`이고 설정·unsupported 형식도 그대로다. `current`에는 이름이 정해진 네 칸의 6,000자 이하 소스 문자열만 허용하며 비트맵·전체 HTML은 거절한다. 20,000자/60,000바이트 전체 본문 제한도 유지한다.

기존 `artMode:'pixel'`, `mode:'pixel'`, `artMode` 없는 2차 route와 구형 전체 HTML 경로를 보존했다. 코드 그림의 프롬프트와 선물의 비율 계약만 의도적으로 강화했다. 모델 `anthropic/claude-haiku-5.5`, reasoning off, slot/route 4,000토큰, SSE·usage·비용 전달, origin 검사·rate limiter·오류 처리는 그대로다.

## 검증

`node --check modules/entry.js`, `node scripts/modular-server-test.cjs` 통과. 모의 upstream으로 서버 **82개 검사**를 수행했으며 외부 AI 호출은 없다. 4차 분류·현재 소스·수동 그림 분기, 그림 계약·재시도, 입력 제한, 3차 픽셀 호환, 2차 요청 데이터·전송 옵션, 구형 전체 HTML 요청 동등성을 확인했다. 증거는 상위 `85_공룡3_모듈화/4차캡처/서버검증결과.json`이다. 실제 AI 인식률·비용·운영 배포는 별도 4차 결과를 따른다.
