# 공룡3 모듈화 3차

> 2026-11-09 보완: 아래는 3차 당시 기록입니다. 현재 AI 밑그림의 자동 보정·39칸 기준과 검증 결과는 [보완 문서](modular-pixel-repair.md)를 따릅니다.

기준은 `85_공룡3_모듈화/설계_3차_손보기.md`다. `modular@c597aaf` 위에서 구현했다. **로컬 구현·자동 검사 완료, 실제 AI 검증은 실패·미완료 항목이 있다. 배포·push 없음.**

## 구현

- `project.js`의 새 작품은 `authoringVersion:3`이다. 이전 메타데이터에 값이 없으면 2로 읽는다. 3차의 캐릭터·장애물·선물은 픽셀 자산만 생성하고, 배경은 기존 검증된 코드 칸을 쓴다. 2차 작품의 코드 칸과 구형 전체 HTML 편집·재생은 보존했다.
- `pixel.js`는 palette 1~8색, `#rrggbb`, 정확한 16×16, 39칸 이상, 캐릭터 상하좌우 최대 연결 덩어리 90% 이상을 검사한다. 잘못된 원본을 자르거나 채우지 않는다. 아이가 손본 그림은 최대 12색, 1칸 이상으로 저장하며 연결·면적을 다시 강제하지 않는다.
- `ai.js`는 검사를 통과한 제안만 반환한다. `chat.js`가 기존 `grade1-pixel.js` 창을 열고 최종 확인에서 저장 성공 후 미리보기를 바꾼다. 취소·검사 실패·저장 실패는 이전 작품을 유지한다. 편집 중에는 AI 시간 제한을 멈추고 재생성 때 다시 시작한다.
- 팔레트는 AI 색 뒤에 기존 기본색을 넣고 총 12색으로 제한한다. 제목·안내·버튼 문구는 설계 그대로다. 기존 CSS, 캔버스·도구·버튼 모양은 보존했으며 AI 창에 작은 닫기 버튼을 추가했다. 직접 그리기는 빈 그림판이다.
- 새 캐릭터 선택과 그 상태의 ‘다시 그려줘’에는 이전 그림을 보내지 않는다. 확인 뒤 ‘다시 그리기’와 9단계 수정에는 현재 그림을 보낸다. 12색 편집 결과도 손실 없이 전달한다. 재생성과 자동 재요청은 별도 boolean으로 보내서 원문 길이가 누적되지 않는다.
- `engine.js`가 픽셀 캐릭터의 숙이기와 마스크 충돌, 장애물 비율 유지·바닥 정렬·색칠칸 충돌·크기 배율·축소, 16×16 선물과 HUD 축소판을 처리한다. 소수 좌표에서도 실제 그림 경계로 충돌 후보를 판정한다.
- 서버 pixel/route 계약, 구조화 응답 보강과 2차 호환은 [server-phase3.md](server-phase3.md)에 있다. 모델·키·SSE는 2차와 같고 pixel 출력 한도는 1,000이다.

서버 73 + 픽셀 29 + 프로젝트 46 + 엔진 65 + 편집기 34 + AI 계약 32 + 통합 56 = **335개 통과**. 실제 AI 자산을 현재 엔진으로 재합성한 `실제AI-최종엔진게임.html`의 `file://` 검사도 별도 **12개 통과**했다. 생성 당시 `실제AI-최종게임.html`과 원시 ledger는 변경하지 않았다.

검사는 외부 요청을 차단하며 가상 수업 번호와 로컬 저장만 사용한다. 수업/게시판 API·DB에 접근하지 않는다. PC 1280×900, 태블릿 1024×768·768×1024의 캔버스 터치·지우개·되돌리기·모두 지우기, X/Esc/바깥 취소, 확인·재생성·저장 실패, 1~9단계, 크게 보기, 이어하기, 내려받은 HTML `file://`, 2차/구형 호환을 확인한다. `grade1-pixel.css`와 직접 그리기 화면은 `c597aaf`와 동일하다.

실제 태블릿 하드웨어와 스피커 청취는 검증하지 않았다. 로컬 Wrangler는 수업 DB 바인딩이 없는 기존 전용 설정과 호환 날짜 2026-10-26을 사용한다. 운영 설정의 날짜 2026-11-01과 배포 환경은 검증하지 않았다.

## 실제 AI 검증과 한계

`scripts/modular-phase3-live-ai-test.cjs`는 `DINO3_LIVE_AI=1`을 명시해야 실행된다. `3차캡처/실제AI기록.json`의 누적 요청 수를 읽고 **20회를 넘는 요청은 외부로 보내지 않는다**. 기존 2차 기록과 별도이며, 한도 초기화를 위해 기록을 삭제하면 안 된다. 키 전달과 로컬 서버 실행은 [2차 문서](modular-phase2.md)의 `serve-modular-ai.cjs` 절차를 사용한다.

총 20회 한도에서 고양이·토끼·바위·선인장·사과·하트·별, 선인장 다시 그려줘 1회, 9단계 캐릭터 색 변경의 밑그림 확인까지 성공했다. 로봇·외계인·상자는 자동 재요청 뒤에도 실패했다. 로봇·외계인·상자는 구조화 응답을 보강하기 전 시험이며, 보강 뒤 재검증할 잔여 한도가 없었다.

두 번째 ‘다시 그려줘’는 실제 AI로 미실시다. 9단계 ‘장애물 더 뾰족하게’는 라우터가 obstacle을 선택하는 것까지 실제 확인했고, 후속 pixel 호출은 20회 제한에 막혔다. 해당 흐름 전체는 모의 SSE 통합 검사에서 통과했다. 실제 AI 검증 전체 통과로 표시하지 않는다.

형식 검사를 통과한 하트도 속이 빈 윤곽으로 나와 ‘가운데 꽉 찬 아이콘’이라는 표현 품질은 부족하다. 원시 밑그림 전체 캡처는 형식 검사와 미술 품질을 구분하기 위해 거절된 그림도 원래 크기와 잘못된 칸 표시 그대로 보존했다.

10번 상자 호출은 스트림 수집 실패로 토큰·비용·시간을 얻지 못했다. 0원으로 계산하거나 한도에서 빼지 않는다. 확인된 19회 SSE 사용량 합계는 전체 비용의 하한이며 누락분을 별도로 표시한다. 12번부터 구조화 응답을 사용했다. 마지막 재생성 boolean 분리와 소수 좌표 충돌 수정은 추가 유료 호출 없이 자동 검사로 검증했다.

`85_공룡3_모듈화/3차결과.md`에 호출별 결과·비용·시간·최종 커밋을, `비용비교.md`에 학생 1명 예상 비용의 가정을 기록했다. 캡처·원시 응답·검사 JSON·실제 생성 단일 HTML은 같은 폴더의 `3차캡처/`에 있다. 이 폴더는 현재 저장소 밖에 있으므로 커밋에는 재현 스크립트와 설명 문서를 포함한다.
